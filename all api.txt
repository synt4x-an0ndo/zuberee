EYARA FASHION — FRONTEND <-> BACKEND API INTEGRATION REPORT
================================================================================
Source of truth for endpoints : readme_frontend.txt  (the backend developer's spec)
Base URL (frontend .env.local) : http://localhost:3001
API client (single fetch layer) : frontend/lib/api.js   (api.get/post/put/patch/delete/upload)
Auth header on every protected call : Authorization: Bearer <JWT>

STATUS LEGEND
  [COMPLETED]  = frontend calls the exact endpoint the backend developer documented
  [FIXED]      = frontend was calling the WRONG path/method; corrected to match the spec
  [NO ROUTE]   = frontend references an endpoint with NO backend route (Section J)
                 -> cannot be connected from the frontend alone (backend files untouched, as requested)
